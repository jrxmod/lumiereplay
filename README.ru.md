# Lumière Play (по-русски)

Это дополнительный файл для тех кто предпочитает читать на русском.

---

## Что это

Мод добавляет блок-проектор. Ставишь его, кликаешь правой кнопкой, вставляешь ссылку на YouTube / Twitch / ВКонтакте или путь к локальному файлу, и на стене появляется виртуальный экран с видео. Работает в одиночной игре и на серверах, другие игроки видят и слышат то же самое. Пока видео идёт, блок прожектора освещает зал, а вокруг экрана появляется мягкая цветная засветка которая следует за оттенком кадра.

---

## Как пользоваться

1. Скрафти Проектор Lumière
2. Поставь: он смотрит в ту сторону куда смотришь ты
3. Правый клик → вставь ссылку или путь к файлу
4. Выбери качество и размер экрана
5. Нажми Play

---

## Общий просмотр

У проектора есть одна общая шкала времени. Play, пауза и перемотка в меню
действуют на всех, кто смотрит этот же проектор, а не только на того кто нажал
кнопку. Качество тоже выбирается одно на всех.

Игрок который зашёл позже, отошёл далеко или отстал из-за буферизации,
подтягивается к общей шкале сам. Один шаг подтяжки ограничен `sync.max_step_ms`,
поэтому после минуты буферизации видео приводится в порядок за несколько
заметных шагов, а не одним телепортом через полфильма.

Источники без известной длительности (прямые эфиры и потоки через pipe: YouTube,
Twitch, VK) не дёргаются вообще: перемотать их нельзя, так что панель отказывает
по кнопке, шкала для них ни к кому не подтягивается и на экране не показывается.
Там позиция может быть учтена только до старта воспроизведения.

## Качество и разрешение

Строчки качества это запрос, а не обещание. Рядом с ними панель печатает размер
который источник реально выдал, оранжевым если сильно не дотянул до запрошенного.
Видимое решают два ограничения:

- Платформенные видео идущие через pipe (YouTube, Twitch, VK) обязаны быть одним
  файлом где аудио уже внутри: yt-dlp не склеивает отдельные видеопоток и
  аудиопоток в stdout. У YouTube смьюксовые варианты это прогрессивный mp4
  (обычно до 360p) и HLS версии (до 1080p), селектор предпочитает HLS, поэтому
  для ролика без HLS версия так и останется ограниченной какой бы кнопку ни нажать.
- Экран рендерится в фиксированную текстуру 1280x720, а на мониторе картинка
  примерно `screenWidth * 16` пикселей в ширину, то есть на экране 16x9 помещается
  около 256x144 деталей скачали хоть 4K. Детали добавляет именно больший экран.

На Windows медиа пишется во временный файл а не в pipe, поэтому там yt-dlp волен
склеить отдельное видео и отдельное аудио, и потолок поднимается прямо сейчас
через `network.ytdlp_args`, без изменений в моде:

```json
"network": { "ytdlp_args": ["-f", "bv*[height<=1080]+ba/b[height<=1080]/best"] }
```

На Linux и macOS тот же список даст предупреждение что два потока пойдут друг за
другом а не в одном контейнере, потому что вывод идёт в stdout: туда нужен муксер
перед pipe, и в этот релиз он не входит.

## Свет в зале

Пока видео идёт, блок прожектора освещает зал, а на паузе или после поломки блока
свет гаснет. Уровень зафиксирован на 12, потому что это общие для всех зрителей
данные мира: он хранится в состоянии блока, поэтому мир сохранённый старой версией
продолжает загружаться а клиент без мода просто не увидит лишнего света.

Кроме того каждый клиент рисует вокруг рамки мягкое свечение оттенок которого
берётся из среднего цвета текущего кадра: ночная сцена даёт синеву а взрыв оранжевый.
Оно не имеет жёсткого края и тает по мере удаления от рамки, появляется только пока
видео реально идёт и прячется там где это место и так освещено небом то есть над
экраном под открытым небом в полдень ничего не рисуется. Эта часть только визуальная
и принадлежит отдельному игроку поэтому `screen.glow_tint` выключает её у себя не
меняя картинку остальных.

## Настройка

Файл `config/lumiereplay.json`, применяется при следующем запуске видео,
перезапуск игры не нужен.

| Ключ | По умолчанию | Что делает |
|------|--------------|------------|
| `screen.bezel_size` | `0.06` | Чёрная рамка вокруг экрана, в блоках |
| `screen.glow_tint` | `true` | Цветная засветка вокруг рамки, зависит от кадра |
| `audio.volume` | `100` | Громкость для проектора который ещё никто не включал |
| `audio.max_distance` | `64.0` | Расстояние где звук затихает до тишины, в блоках |
| `lazy.pause_distance` | `96` | Дальше этого расстояния видео ставится на локальную паузу |
| `network.proxy` | `""` | Прокси для yt-dlp и ffmpeg, например `http://127.0.0.1:7890` |
| `network.vlc_args` | `[]` | Дополнительные аргументы libvlc для каждого плеера |
| `network.ytdlp_args` | `[]` | Дополнительные аргументы каждого вызова yt-dlp, ставятся после своих и потому перекрывают их |
| `history.max_entries` | `5` | Сколько ссылок помнит меню |
| `sync.enabled` | `true` | Держать зрителей на общей шкале времени |
| `sync.threshold_ms` | `1500` | Минимальная рассинхронизация ради которой стоит перематывать |
| `sync.check_interval_ms` | `5000` | Как часто сверять себя с общей шкалой |
| `sync.grace_ms` | `4000` | Пауза после старта или перемотки, когда ничего не подтягивается |
| `sync.max_step_ms` | `30000` | Самый большой прыжок одной подтяжки, большие разрывы закрываются за несколько шагов |
| `sync.jump_on_join` | `false` | Для потоков через pipe открывать видео сразу с общей позиции если зритель присоединился позже. Плюс одна лишняя ступенька разрешения ссылки |

## Что нужно установить

На клиенте нужен VLC Media Player:

    Linux:   sudo pacman -S vlc   или   sudo apt install vlc
    Windows: https://www.videolan.org/vlc/
    macOS:   brew install vlc

yt-dlp скачается сам если его нет в системе.

На сервере ничего дополнительно не нужно.

## Поддерживаемые платформы

- YouTube (нужно быть залогиненным в браузере)
- Twitch: прямые трансляции и VOD
- Vimeo, Dailymotion, SoundCloud
- ВКонтакте / vkvideo.ru
- Rutube
- ok.ru/video
- Локальные файлы: абсолютный путь начиная с /

Яндекс.Видео не работает, сломан экстрактор в yt-dlp на их стороне.

## Версии

Пакеты управления проектором имеют два формата. Клиент 0.7.0 на сервере со
старой версией мода продолжает работать, но перемотка для всех и общее качество
работают когда обе стороны обновлены до 0.7.0 или новее.
